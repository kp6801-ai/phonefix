# Security

phonefix runs Playwright against a URL or folder you choose and edits files only through your own AI agent. It makes no network calls of its own except the optional GitHub stars badge on the landing page.

If you find a vulnerability (for example a way for a scanned page to execute code on the machine running the scripts), email kp@spikestudiodxb.com. Do not open a public issue. You will get a reply within a week, and credit in the fix if you want it.

Scope: everything under `skills/phonefix/`, `adapters/` and the installer. The landing page and demo pages are static HTML.
